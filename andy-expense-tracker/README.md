# Andy Expense Tracker v1

A personal expense tracking web app.

## Current features
- Add, edit and delete expenses
- Daily / weekly / monthly totals
- Month-on-month comparison
- Monthly budget and remaining amount
- Category breakdown
- Payment method breakdown
- Personal / Momenti Studios / DVC Business / Home expense type
- Search and filters
- JSON export/import backup
- Mobile responsive layout
- Browser localStorage persistence

## Next phase
- Supabase database + login
- Multi-device sync
- Receipt image attachment
- ChatGPT-to-database secure expense endpoint
- Monthly/yearly reporting

## Run
Open `index.html` in a browser, or deploy the folder to Cloudflare Pages / Vercel / GitHub Pages.
